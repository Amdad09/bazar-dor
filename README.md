# 🛒 bazar-dor

**সঠিক দামের সহজ সন্ধান।**

bazar-dor is a web-based product price discovery and comparison platform that helps users explore product prices and make informed purchasing decisions.

The goal of bazar-dor is to make it easier for users to discover products, compare prices, and identify suitable purchasing options without unnecessary effort.

## 🎯 Project Purpose

Online shopping offers many choices, but finding the right product at a suitable price can be time-consuming. bazar-dor aims to simplify this process by providing a convenient platform for product discovery and price comparison.

## ✨ Key Features

- 🔐 **Secure Authentication** — User registration and sign-in using Better Auth.
- 🌐 **Social Login** — Google and GitHub authentication.
- 🔎 **Product Discovery** — A platform focused on finding and exploring products.
- 💰 **Price Comparison** — Designed to help users compare product prices and make better purchasing decisions.
- 📱 **Responsive Interface** — A user-friendly experience across different screen sizes.
- 🧭 **Simple Navigation** — Clear navigation and a custom 404 page.

## 🛠️ Built With

- Next.js
- TypeScript
- Tailwind CSS
- HeroUI
- Better Auth
- MongoDB
- Sonner
- React Icons and Gravity UI Icons

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd bazar-dor
npm install
```

Configure the required environment variables in `.env.local`, then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌟 Vision

bazar-dor aims to make product price discovery simpler, help users compare available options, and support smarter purchasing decisions.
